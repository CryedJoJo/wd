

# **8-变量详解**

1、可以理解为 c++中变量的唯一区别就是数据类型所占用的 内存大小

2、如果定义float f = 5.5，那么f将是一个双精度浮点数，如果需要将f的实际格式设置为单精度浮点数，那么需要在5.5后面加个f，既5.5f

3、计算机中，地址是按照字节寻址的，而bool类型逻辑上是只需要1位来表示，既一位来表示0或1。因为计算机中按字节寻址，无法直接读取某一位的数据，使用计算机中用bool类型时，都是将地址所在数据整体当真bool类型判断，如果数据整体值是0就是false，非0就是true。一般来说，bool是占用1个字节 8位，如果用if(type) 时，这儿的type类型就是用是否为0来判断了。

# **9-函数详解**

函数，就是我们编写的代码块，用于执行特定的任务，程序代码就是由一堆函数组成的。

1、属于类的函数一般我们称这种函数为类的方法，不属于类的函数我们一般就叫他函数，当说方法时 就一定说明它是属于类的函数

2、

使用函数的规则：

1、你应该把代码拆分为很多的函数，但没必要每行代码都写一个函数

因为，每次我们写一个函数，编译器会生成一条调用指令，这意味着，在运行的程序中，为了调用一个函数，我们需要为一个函数创建整个栈帧，也就是将参数，ebp，esp之类的东西压入栈中，然后跳转到二进制文件的其他部分，以便执行函数指令。我们压入的返回值之后会找回来，以便回到之前的位置。所以，为了执行函数指令，整个过程就像在内存里面跳来跳去，函数太碎了就会进行频繁的压栈，弹栈，这会拖慢程序的运行速度。

2、基本上，要是你发现自己多次在做同一项任务，那就为它创建一个函数。函数的主要目的就是防止代码重复。

3、除了main函数这一特殊函数，只要有返回值类型的函数都需要返回一个值。

# **10-头文件详解**  

头文件的功能就是在预处理时将头文件中的内容替换到包含了头文件的文件中，就是简单的复制，为被调用到的函数做声明，好让编译器知道有相关的函数。如果不使用头文件的话，也有办法可以让代码正常编译链接，只是我们要在使用到外部函数的地方都做一次函数声明

## 1、不使用头文件方式：

main.cpp

```c++
#include<iostream>

void Log(const char* message) //函数签名
{ //函数实现
    std::cout << message << std::endl;
}

int main(){
    Log("hello World!");
    std::cin.get();
}
```

log.cpp

```C++
void Log(const char* message); //函数声明，告诉下面的调用，这个函数存在

void InitLog()｛
    Log("str");
｝
```

## 使用头文件方式

log.h

```c++
#pragma once //以#号开头的头上预处理指令，他是发给预处理器的
//他是防止头文件在同一个翻译单元中重复包含，如果没有这个指示 可能会导致单个cpp中多次包含下面的声明
void Log(const char* message); 
void InitLog();
```

log.cpp

```c++
#include "log.h"

#include <iostream>

void InitLog()｛
    Log("str");
｝

void Log(const char* message) //函数签名
{ //函数实现
    std::cout << message << std::endl;
}
```

main.cpp

```c++
#include "log.h"

#include<iostream>

int main(){
    Log("hello World!");
    std::cin.get();
}
```
